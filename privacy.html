Privacy Policy – MayRain upload tool (ambient-factory)

Last updated: 1 October 2026

The MayRain upload tool ("ambient-factory") is a private application used only by the owner of the MayRain YouTube channel to upload the channel's own original videos, titles, descriptions and thumbnails.

Use of YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Information we access, collect and use

When the owner signs in with Google (OAuth 2.0), the tool receives an authorization token for the owner's own YouTube channel. It uses this token only to upload videos, set video titles, descriptions, tags, privacy status and thumbnails on that channel. The tool does not read, collect or display any data about other YouTube users, viewers, comments or channels.

Storage

The authorization token is stored only on the owner's private server. Video files and their text are stored on the same server until they are uploaded, then deleted. No cookies are placed on any device by this tool.

Sharing

No data is sold or shared with third parties. Data is sent only to Google/YouTube, to upload the videos.

Revoking access

You can revoke the tool's access to your Google account at any time from the Google security settings page: security.google.com/settings/security/permissions.

Deletion of data

When access is revoked, or on request by email to the contact below, the stored authorization token and any related data are deleted from the server within 7 days. The tool never keeps YouTube API data for more than 30 days.
