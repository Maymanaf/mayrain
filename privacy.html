Privacy Policy – MayRain upload tool

Last updated: 1 October 2026

The MayRain upload tool is a private application used only by the owner of the MayRain YouTube channel to upload the channel's own original videos, titles, descriptions and thumbnails.

Data we access

With the owner's permission, the tool uses the YouTube Data API to upload videos and thumbnails to the owner's own channel. It does not read, collect, store or share any data about other YouTube users or viewers.

Data storage

The authorization token is stored only on the owner's private server and is used only to upload the channel's own videos. No data is sold or shared with third parties.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service (youtube.com/t/terms) and the Google Privacy Policy (policies.google.com/privacy). You can revoke access at any time at myaccount.google.com/permissions.
